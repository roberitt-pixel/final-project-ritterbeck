# Beam Checker

A Drafter website for checking whether a simply supported beam is safe. Enter the beam (length, material, cross-section), add point or uniform loads, and the site shows the support reactions, largest bending moment, largest bending stress, a safety factor, and a SAFE / UNSAFE verdict.

Files: beamchecker.py (the site), llm\_conversation.md, the Week 10 and Week 11 worksheets, and the video link.
